# WhatsApp Local Agent

This folder contains the locally hosted WhatsApp agent that controls WhatsApp Web via a browser automation tool (like Puppeteer or Playwright).
It is triggered by the BRMS backend when an admin clicks "Launch WhatsApp Campaign".

## Features
- Connects to WhatsApp Web locally.
- Receives message templates and product links from the backend.
- Automates sending messages to groups or individuals using the pre-configured variables.
